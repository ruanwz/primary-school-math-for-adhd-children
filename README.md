# 小学数学ADHD学习助手

## 项目简介

这是一个专为有ADHD症状的中国小学生设计的数学学习Web应用。应用充分考虑ADHD儿童的注意力特点，提供：

- 🎮 **高度游戏化**：积分、徽章、关卡系统
- 🎨 **强视觉吸引力**：动画、色彩丰富的界面
- ⚡ **短时学习单元**：每个模块5-10分钟
- 🎯 **即时反馈**：立即的正面反馈和鼓励
- 📊 **清晰进度追踪**：可视化的学习进度
- 🧩 **高互动性**：点击、拖拽、动画互动

## 教学内容

覆盖中国小学数学教纲2-6年级内容：

### 二年级
- 100以内加减法
- 表内乘法口诀
- 认识图形
- 长度和时间

### 三年级
- 万以内加减法
- 表内除法
- 多位数乘法
- 分数初步认识

### 四年级
- 大数的认识
- 四则运算
- 小数的认识和运算
- 图形面积

### 五年级
- 小数乘除法
- 分数加减法
- 长方体和正方体
- 简易方程

### 六年级
- 分数乘除法
- 比和比例
- 圆的认识
- 统计与概率

## ADHD友好设计原则

1. **注意力管理**
   - 学习时间分块（5-10分钟）
   - 进度保存，随时暂停
   - 避免信息过载

2. **视觉设计**
   - 大按钮、清晰图标
   - 高对比度配色
   - 动画引导注意力

3. **即时反馈**
   - 答对立即播放鼓励动画
   - 答错提供友好提示
   - 进度条实时更新

4. **奖励机制**
   - 完成任务获得星星
   - 收集徽章和成就
   - 可爱的角色陪伴

## 技术栈

### 后端
- Python 3.9+
- Flask (Web框架)
- SQLAlchemy (数据库ORM)
- SQLite (数据库)

### 前端
- React 18
- TypeScript
- TailwindCSS (样式)
- Framer Motion (动画)
- React-Three-Fiber (3D可视化)

### 可视化
- Manim (数学动画)
- P5.js (互动图形)
- Chart.js (进度图表)

## 快速开始

### 安装依赖

```bash
# 安装后端依赖
cd backend
pip install -r requirements.txt

# 安装前端依赖
cd ../frontend
npm install
```

### 运行应用

```bash
# 启动后端服务器
cd backend
python app.py

# 启动前端开发服务器
cd frontend
npm start
```

应用将在 http://localhost:3000 打开
